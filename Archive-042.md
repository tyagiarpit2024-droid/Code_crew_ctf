## Challenge Description
We were tasked with decrypting entries from the Ministry of Records:

> "The Ministry of Records seals each archive entry with its own one-time exponent. The clerk publishes base^secret mod modulus as the entry's element, keeps the secret, and encrypts the entry with a SHA-256 counter-mode keystream. The Ministry's auditors chose the modulus. They were proud of its size, and less careful about its structure. Archive 042 holds two entries, and only one of them is what you're looking for."

Required flag format: `VOID{...}`

---

## Step-by-Step Solution

### Step 1: Analyze the Cryptographic Parameters
From `archive.json`:
* **Modulus ($p$):** `7970443641581079859201` (73 bits)
* **Base ($g$):** `3`
* **Nonce:** `984124905`
* **Two records:**
  * Record 1: Public element $h_1 = 4697966779435071191060$
  * Record 2: Public element $h_2 = 349040605092574909546$

Each record is generated via:
$$h_i \equiv g^{x_i} \pmod p$$
and encrypted with a keystream generated by SHA-256 in counter mode.

---

### Step 2: Factorizing $p - 1$ (Smooth Modulus Vulnerability)
Factoring $p - 1$:
$$p - 1 = 7970443641581079859200$$
$$p - 1 = 2^{12} \times 3^4 \times 5^2 \times 7 \times 11 \times 13 \times 959982778793$$

Notice that all factors of $p - 1$ are tiny, except for a single prime $q = 959982778793 \approx 9.6 \times 10^{11}$.
The square root of this maximum factor is:
$$\sqrt{q} \approx 979\,787$$

Because $\sqrt{q} < 10^6$, this is an ideal target for the **Pohlig–Hellman algorithm** combined with **Baby-step Giant-step (BSGS)**.

---

### Step 3: Pohlig–Hellman Algorithm + BSGS
To find $x$ such that $g^x \equiv h \pmod p$:
1. For each prime power $q_i^{e_i} \mid (p - 1)$, project the base and element into the subgroup of order $q_i^{e_i}$:
   $$g_{\text{sub}} \equiv g^{(p-1)/q_i^{e_i}} \pmod p, \quad h_{\text{sub}} \equiv h^{(p-1)/q_i^{e_i}} \pmod p$$
2. Recover the $q_i$-adic digits of $x \pmod{q_i^{e_i}}$ by solving discrete logarithms in the base subgroup of order $q_i$.
   * For the small factors ($2, 3, 5, 7, 11, 13$), discrete logs resolve almost instantly.
   * For the largest factor $q = 959982778793$, BSGS finishes in $< 10^6$ steps (~1 second).
3. Using the **Chinese Remainder Theorem (CRT)**, combine the residues $x \pmod{q_i^{e_i}}$ to obtain the unique secret $x \in [0, p-2]$:
   * **Record 1 Secret:** $5975398336546460702697$
   * **Record 2 Secret:** $7808714507196815371592$

Verification confirms $g^{x_i} \equiv h_i \pmod p$ for both records.

---

### Step 4: Reconstruct Keystream and Decrypt
The encryption uses SHA-256 counter mode. For a given secret, nonce, and integer counter $i \ge 0$:
$$\text{block}_i = \text{SHA-256}(\text{f"}\{\text{secret}\}:\{\text{nonce}\}:\{i\}\text{"})$$

Concatenating blocks and XORing with the ciphertext reveals the plaintexts:
* Record 1: Decrypts to a routine administrative memo.
* Record 2: Decrypts to the flag:
  `VOID{smooth_orders_still_hide_one_large_digit}`

## Exploit Script

```python
import hashlib
import json
import math

challenge = {
    "modulus": 7970443641581079859201,
    "base": 3,
    "nonce": 984124905,
    "records": [
        {
            "id": 1,
            "element": 4697966779435071191060,
            "data": "1f88575a2fa44a861d80be951aeb150c99a8cb406c117b9fe7926e2fae5cfec2cb47",
        },
        {
            "id": 2,
            "element": 349040605092574909546,
            "data": "a1e44b36bc19f7c0826936847e838275d6539645101ee918ee4fd1f3c5bd9b9c2438393c7e",
        },
    ],
}

p = challenge["modulus"]
g = challenge["base"]
nonce = challenge["nonce"]
factors = [(2, 12), (3, 4), (5, 2), (7, 1), (11, 1), (13, 1), (959982778793, 1)]


def bsgs(base, target, order, mod):
    m = math.isqrt(order) + 1
    tbl = {}
    cur = 1
    for j in range(m):
        tbl[cur] = j
        cur = (cur * base) % mod
    step = pow(base, order - (m % order), mod)
    cur = target % mod
    for i in range(m):
        if cur in tbl:
            return i * m + tbl[cur]
        cur = (cur * step) % mod
    return None


def pohlig_hellman(base, target, factors, mod):
    order = mod - 1
    remainders, moduli = [], []
    for q, e in factors:
        qe = q**e
        g_sub = pow(base, order // qe, mod)
        h_sub = pow(target, order // qe, mod)
        gamma = pow(g_sub, q ** (e - 1), mod)
        x = 0
        q_pow = 1
        g_inv = pow(g_sub, -1, mod)
        for k in range(e):
            h_k = pow((h_sub * pow(g_inv, x, mod)) % mod, q ** (e - 1 - k), mod)
            d = bsgs(gamma, h_k, q, mod)
            x += d * q_pow
            q_pow *= q
        remainders.append(x)
        moduli.append(qe)

    x = 0
    for r_i, m_i in zip(remainders, moduli):
        M_i = order // m_i
        inv = pow(M_i, -1, m_i)
        x = (x + r_i * M_i * inv) % order
    return x


def decrypt(secret, nonce, ciphertext_hex):
    ct = bytes.fromhex(ciphertext_hex)
    keystream = b""
    counter = 0
    while len(keystream) < len(ct):
        keystream += hashlib.sha256(
            f"{secret}:{nonce}:{counter}".encode()
        ).digest()
        counter += 1
    return bytes(c ^ k for c, k in zip(ct, keystream[: len(ct)]))


for rec in challenge["records"]:
    secret = pohlig_hellman(g, rec["element"], factors, p)
    plaintext = decrypt(secret, nonce, rec["data"]).decode("utf-8")
    if plaintext.startswith("VOID{"):
        print(f"Decrypted Flag: {plaintext}")
```
